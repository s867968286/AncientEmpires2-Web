建筑与地形 · 增益一览

站在建筑或地形格上会获得“护甲”（减伤），建筑还提供回血与金币。护甲取建筑与地形中较高的那一项（建筑优先）。

升级系统 · 成长曲线

单位通过战斗获得经验（XP）自动升级；初始为 0 级（0 XP，无加成）。每提升 1 级，攻击 +2、防御 +2（源码 atkByLevel / defByLevel = 2）。

⛨ 伤害结算（简化）
实际伤害 ≈ (攻方攻击力 + 等级×2 + 各种增益 − 减益) × 攻方血量比例
− (守方防御 + 等级×2 + 地形/建筑护甲 + 各种增益) × 攻方血量比例
伤害最低为 1，且不超过守方剩余生命。“血量比例 = 当前生命 / 100”，因此残血单位输出会下降。
等级（从 0 起）所需经验 XP累计攻击加成累计防御加成

取“不超过当前 XP 的最高档”：0 级 = 0 XP（无加成），攒到 84 XP 才升 1 级（+2/+2）；9 级 = 926 XP（攻防各 +18，满级）。
